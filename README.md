# UZMOVi Loyihasi

## Loyihani ishga tushirish

Loyihani ishga tushirish uchun quyidagi qadamlarni bajaring:

1. Node.js va npm o'rnatilganligiga ishonch hosil qiling
2. Loyiha jildiga terminal orqali o'ting
3. Kerakli paketlarni o'rnating:

```bash
npm install
```

4. Serverni ishga tushiring:

```bash
npm start
```

Yoki rivojlantirish rejimida ishga tushirish uchun:

```bash
npm run dev
```

5. Brauzeringizda `http://localhost:5500` manziliga tashrif buyuring.

## 404 xatolik sahifasi

Mavjud bo'lmagan URL manziliga kirilganda avtomatik ravishda 404 sahifasiga yo'naltiriladi.

## Loyiha tuzilishi

- `index.html` - Bosh sahifa
- `serialar.html` - Seriallar sahifasi
- `player.html` - Video ijro etuvchi sahifa
- `404.html` - Sahifa topilmaganda ko'rsatiladigan sahifa
- `data.js` - Loyiha ma'lumotlari
- `server.js` - Node.js serveri
